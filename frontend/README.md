# Client Tunisian Capitalist

Installation : `npm ci`. Démarrage : `npm start`, puis http://localhost:4200.

Le backend doit être démarré sur le port 3000.

Compilation : `npm run build`. Tests : `npm run test:ci` (Google Chrome requis).

Après modification des opérations GraphQL : `npm run codegen`.

Les instructions complètes et les règles du jeu figurent dans le [README du projet](../README.md).
