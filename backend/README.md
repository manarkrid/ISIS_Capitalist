# Serveur Tunisian Capitalist

Installation : `npm ci`. Démarrage : `npm run start:dev`.

API : http://localhost:3000/graphql. Images : `/icones/`.

Compilation : `npm run build`. Exécution du résultat : `npm run start:prod`.

Tests métier : `npm test`. Tests de l'API GraphQL : `npm run test:e2e`.

Les instructions complètes et les règles du jeu figurent dans le [README du projet](../README.md).
